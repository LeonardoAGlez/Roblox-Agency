# Informes de validación

Crear informes con fecha y tarea, siguiendo `tasks/templates/delivery.md`. Conservar aquí resúmenes legibles y enlazar logs, capturas y manifiestos ubicados en `artifacts/` (no versionados). Si la evidencia solo existe localmente, indicarlo.

Cada resultado debe ser aprobado, fallido o no ejecutado. Identificar versión del código y del entorno. Este archivo describe el procedimiento; los resultados de ejecución se registran en informes separados.

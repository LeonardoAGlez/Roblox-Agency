# Brief de producto

## Objetivo actual

Preparar un equipo de desarrollo Roblox desde Codex y demostrar una función local completa antes de elegir el juego comercial.

## Decisiones pendientes del propietario

- Concepto, género, público y dispositivos prioritarios.
- Presupuesto y objetivos económicos.
- Nombre comercial y autorización para publicar.

El primer encargo de diseño propondrá conceptos con ciclo de juego, coste relativo, riesgo técnico y una prueba pequeña para validar interés. El contador de esta base es una demostración técnica; no representa un concepto aprobado.

## Aceptación de la base

Ocho especialistas descubribles, cinco skills, proyecto reconstruible con Rojo, comprobaciones estáticas, pruebas de servidor y un playtest del contador con evidencia. Cada resultado debe distinguir aprobado, fallido y no ejecutado.
